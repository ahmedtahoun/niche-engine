# deploy branch

This branch is generated by GitHub Actions from `main`. Do not edit it by hand.

It contains the built server (`apps/web/server.js`), its minimal `node_modules`, the static files and the niche settings. cPanel pulls it and runs `.cpanel.yml`.

`REVISION` holds the `main` commit this build came from.

## Photos and build files served by the web server

On every deploy, `.cpanel.yml` also copies `products/`, `brands/`, `sellers/` and `_next/static/`
into cairoroast.com's web folder (`/home/viorowzb/cairoroast.com`). The web server sends files
that exist there itself, cached by the browser (the small `.htaccess` in each folder sets how long),
and passes every other request to the Node app. Nothing to do by hand; the root `.htaccess` is untouched.
